🔴 Must Have — Ship Blockers
🔐 Auth & Route Guards
Every protected route must redirect unauthenticated users. JWT expiry handling, silent refresh, logout-on-401. No exposed pages.
useAuthGuard · axios interceptors
💥 Error Boundaries
React Error Boundaries wrapping every major section. Without this, one JS crash kills the entire app for the user.
ErrorBoundary · fallback UI
🌐 Environment Config
VITE_API_URL, VITE_ENV properly set per environment. No hardcoded localhost URLs in production bundles.
.env.production · Vite env
📦 Build Optimization
Tree shaking, code splitting by route, gzip/brotli. A 5MB bundle will fail on Thai mobile networks. Target <200KB initial JS.
vite build · rollupOptions
🔒 HTTPS + Security Headers
CSP, X-Frame-Options, HSTS. Set at CDN/reverse proxy level (nginx/Cloudflare). Prevents XSS and clickjacking.
nginx headers · Cloudflare
⚠️ Global Error Tracking
Sentry or equivalent. You need to know when users hit errors — you won't find out otherwise until churn happens.
Sentry · @sentry/react
🟠 Important — Ship Within First Sprint
⏳ Loading & Skeleton States
Every async operation needs a loading state. Blank screens feel broken. Skeleton screens feel fast.
Suspense · skeleton components
📱 Responsive Layout
Even B2B users check dashboards on tablets. At minimum, don't break at 768px. Your Thai agency clients will use iPads.
Tailwind breakpoints
🔄 API Error Handling (UI)
Toast/snackbar for failed requests. Retry logic for 5xx. Clear messages when the backend is down.
react-query · toast
🧪 Smoke Tests (E2E)
At minimum: login flow, create workflow, run workflow. Prevents you from shipping a broken login page to prod.
Playwright · Vitest
🗜️ Asset Optimization
Compress images, use WebP, lazy-load below-fold assets. Fonts subset to Thai + Latin only if targeting TH market.
vite-imagetools · font-display
📊 Analytics
You need to know which features users actually use. Posthog or Mixpanel. Without this you're flying blind on roadmap decisions.
Posthog · event tracking
🚀 CI/CD Pipeline
Automated build + deploy on push to main. Manual deployments cause human error. GitHub Actions → S3/CDN or Vercel.
GitHub Actions · Vercel
🟣 Nice to Have — Post-Launch
♿ Accessibility (a11y)
ARIA labels, keyboard navigation, contrast ratios. Not legally required in TH yet, but a quality signal.
axe-core · WCAG AA
🌏 i18n (Thai/English)
If targeting Thai agencies, localization will matter. Set up react-i18next structure early — retrofitting is painful.
react-i18next
📈 Web Vitals Monitoring
Core Web Vitals (LCP, FID, CLS). Matters more if you have a public marketing site. Less critical for app behind login.
web-vitals · Lighthouse CI
🏳️ Feature Flags
Ship incomplete features safely behind flags. Enables gradual rollouts. Useful once you have multiple plan tiers (Free/Team/Agency).
LaunchDarkly · Posthog flags
